# بطاقتي | Bitaqati

موقع عربي بسيط ومتجاوب لتصميم بطاقات المناسبات القابلة للطباعة.

## المزايا
- قوالب للزفاف والخطوبة وأعياد الميلاد والمولود والتخرج والعيد والشكر.
- تعديل العنوان والنص والأسماء والتاريخ والمكان.
- ألوان وأنماط متعددة.
- تنزيل البطاقة بصيغة PNG.
- طباعة البطاقة أو حفظها PDF من نافذة الطباعة.
- لا يحتاج الموقع إلى تسجيل دخول ولا يرسل النصوص التي تكتبها إلى خادم.

## النشر على GitHub Pages
1. افتح Settings في المستودع.
2. افتح Pages.
3. ضمن Build and deployment اختر GitHub Actions كمصدر إذا طلب منك ذلك.
4. افتح تبويب Actions وتابع سير العمل Deploy Bitaqati to GitHub Pages.

بعد نجاح النشر، رابط الموقع المتوقع:
https://obaidahshteiwi.github.io/bitaqati/
